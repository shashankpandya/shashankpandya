## 🚀 Featured Projects

### [Aira — AI Technical Interview Coach](https://github.com/shashankpandya/Aira)
> Voice-first multilingual technical interview coach for Tier-2/3 cities in India

**The Problem:** Students lack access to affordable, quality interview prep. Existing platforms are English-only, expensive, and require broadband.

**The Solution:** Serverless WhatsApp-native coach using AWS pipeline — voice notes transcribed via Amazon Transcribe, graded by Gemini AI, with spoken feedback via Polly. Zero app install required.

| Impact | Metrics |
|--------|---------|
| Handles 1,000+ concurrent users | ~$1.31/user/month |
| Supports Hinglish/Hindi voice | AWS AI for Bharat Hackathon |

**Tech:** `Python` `AWS Lambda` `EventBridge` `DynamoDB` `Amazon Transcribe` `Amazon Polly` `Gemini AI` `WhatsApp API`

---

### [Crypto Portfolio Tracker](https://github.com/shashankpandya/Crypto_Portfolio)
> Privacy-first, offline-capable crypto portfolio dashboard

**The Problem:** Crypto investors lack a privacy-first way to track holdings without third-party data exposure.

**The Solution:** Full-stack dashboard with React/Vite frontend, IndexedDB for offline persistence, Chart.js visualizations, and smart contracts for on-chain verification.

| Impact | Features |
|--------|----------|
| Complete data ownership | No account required |
| Offline-first architecture | No cloud dependency |

**Tech:** `React` `Vite` `Node.js` `Solidity` `Hardhat` `Chart.js` `IndexedDB`
